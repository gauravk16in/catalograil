## Notes for whoever builds the embedding client (T1.15)

**The profile prefix is `global.`, not `apac.`.** Embed v4 refuses on-demand invocation —
`cohere.embed-v4:0` returns a ValidationException telling you to use an inference profile,
and the plausible-looking `apac.cohere.embed-v4:0` is simply not a valid identifier. The
profile id was found with `ListInferenceProfiles`, not guessed, and it should be re-read
that way rather than hard-coded from memory if the region ever changes.

`global.` means requests may be served outside `ap-south-1`. That is a data-residency
question worth answering before production, since product text and images leave the region.

**Text and image take different request bodies on the same model.** Text works with the v3
style `{ texts: [...] }`; image needs the v4 style `{ inputs: [{ content: [...] }] }`. A
client that assumes one shape for both will fail on whichever it did not implement.

**Both modalities return 1024 dimensions**, so the `vector(1024)` columns in
`searchable_units` are correct as migrated. No schema change is needed.
